1. Servidor MCP Travel Copilot

Desarrollo de un Model Context Protocol (MCP) que actúa como copiloto inteligente para estructurar y orquestar viajes complejos multiciudad, conexiones de transporte, hotelería y presupuestos multidivisa con validación temporal.

Capacidades Técnicas & Primitivas MCP:
  • Tools: add_itinerary_segment (registra traslados de avión, tren o bus y reservas con horarios de check-in/out, estaciones y código de confirmación), check_schedule_conflicts (evalúa viabilidad temporal y alerta márgenes críticos o solapamientos entre conexiones), track_budget_expense (control de gastos estimados vs. reales en EUR, USD y ARS con conversión cambiaria).
  • Resources: trip://itinerary/current (expone el itinerario consolidado día a día en JSON estructurado para inyección directa de contexto al LLM en tiempo de ejecución).
  • Prompts: suggest-daily-route (analiza atracciones seleccionadas por el usuario en una ciudad y sintetiza recorridos geográficamente eficientes minimizando tiempos de traslado).
E-commerce Transaccional Full-Stack · Mercado Pago API · Webhooks
